# Nutri — beta web per iPhone

Questa repository ospita esclusivamente la procedura di pubblicazione e gli artefatti web distribuiti nelle release. Non contiene il repository sorgente privato, credenziali, archivi personali o dati di Home Assistant. Gli artefatti non vengono committati nel repository.

Apri la beta da https://and87.github.io/nutri-iphone-beta/ con Safari e scegli **Condividi → Aggiungi alla schermata Home**. Il primo avvio richiede rete; attendi la disponibilità offline. I dati nuovi restano su quel dispositivo. Per Nutribot serve l’invito privato ricevuto dal proprietario.

Usa il backup cifrato prima di cancellare l’app o i dati del sito. La beta web non certifica le integrazioni hardware dell’app nativa.
